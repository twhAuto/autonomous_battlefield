# Component map

Most `internal` packages are shared, so a package's folder doesn't say which process
runs it. The table below lists, for each internal package, the binaries that link it,
directly or transitively. For example, `ai/decision` runs in the engine (scripted
factions), the AI gateway (model submissions) and the offline AI evaluation.

[`test/boundaries`](../../backend/test/boundaries/boundaries_test.go) generates
the table and fails `go test` when it is stale. Regenerate it from `backend/` with:

```bash
go test ./test/boundaries -run TestComponentMapIsCurrent -update
```

The same test enforces forbidden dependencies. For example, the agent links no database
code, only the engine links `battle/worker`, and `internal/game` links no AI or
persistence code. Domain services link no repository, HTTP or database adapters, and
HTTP handlers reach storage only through their service. Add a rule there when you
introduce a new boundary.
