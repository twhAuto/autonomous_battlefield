# Autonomous Battlefield

Read and follow [AGENTS.md](AGENTS.md) for standing rules, branch targets,
verification requirements, and review limits. Project skills are discoverable
through `.claude/skills/`, which links to the canonical `.agents/skills/`
directories. Read the relevant linked `SKILL.md` before starting that workflow;
for PR preparation use
[raise-pr](.agents/skills/raise-pr/SKILL.md); for CI failures use
[triage-ci](.agents/skills/triage-ci/SKILL.md); for promotion or recovery use
[release-and-recover](.agents/skills/release-and-recover/SKILL.md); for major
documentation work use
[write-project-docs](.agents/skills/write-project-docs/SKILL.md); for Notion
backlog tickets use [track-backlog](.agents/skills/track-backlog/SKILL.md).
Follow [the cross-review guide](docs/developer/cross-review.md) for the
actual reviewer invocation and author-response protocol.
